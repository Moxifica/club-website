Main project

AI-Interface OSPF NAT

To configure a router or switch, one must enter the command line and know how to operate it. There are thousands of commands that often cause delays or prolongue troubleshooting for industry experts. Our goal is to give people a graphical interface in which they can use natrual language instead for interaction.

We’re developing an AI-powered application to configure, monitor, troubleshoot, and manage Cisco networking equipment. The aim is to make those tasks accessible to people who are still learning Cisco CLI commands and lessen the work load for network specialists.

Example request:
“Which router interfaces are down?”

A question a user could ask the proposed interface.
